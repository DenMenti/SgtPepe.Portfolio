# Sergente Pepe — portfolio

Portfolio personale di Denis Sentimenti (Sgt. Pepe), senior art director.

Sito statico in un unico file: `index.html` contiene HTML, CSS, JavaScript,
i pittogrammi dell'immagine coordinata in SVG e le immagini dei progetti
incorporate. Nessuna dipendenza da installare, nessun passaggio di build.

Pubblicato con GitHub Pages: https://denmenti.github.io/SgtPepe.Portfolio

## Modifiche

Si modifica direttamente `index.html`. I punti utili sono segnalati da commenti:

- `<!-- ↓↓↓ PAYOFF ... -->` — le quattro righe di apertura della home
- `<!-- altre immagini del progetto: aggiungile qui dentro -->` — galleria di ogni scheda progetto
- il logo flush nella barra in alto è ancora un segnaposto testuale

Dopo ogni modifica:

    git add -A && git commit -m "descrizione della modifica" && git push
