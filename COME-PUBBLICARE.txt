PUBBLICARE IL SITO
==================

Qui è già tutto pronto: file aggiunti, commit fatti, remote impostato su
https://github.com/DenMenti/SgtPepe.Portfolio.git (il repository esiste già
ed è vuoto, in attesa del primo push).

Manca solo il push, che richiede il tuo accesso a GitHub.


APRI IL TERMINALE DEL MAC E INCOLLA:

    cd ~/Sites/SgtPepe.Portfolio && git push -u origin main

GitHub ti chiederà di autenticarti: si apre il browser, confermi, fine.
(Se chiede utente e password, la password NON è quella del tuo account ma un
token: in quel caso premi invio e lascia che apra il browser.)


POI DIMMELO: attivo io GitHub Pages dalle impostazioni del repository.
Il sito sarà online su:

    https://denmenti.github.io/SgtPepe.Portfolio/


AGGIORNARE IL SITO IN FUTURO
----------------------------
Modifichi index.html, poi:

    cd ~/Sites/SgtPepe.Portfolio
    git add -A
    git commit -m "cosa hai cambiato"
    git push
